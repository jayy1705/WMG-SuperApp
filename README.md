# WMG-SuperApp
WMG SuperApp is a combination of 3 previously seperated programs, Converting invoices into workable excel dataset, cleaning and grouping the dataset, and finally visualize it into 2 exportable pdf files (Yearly Sales Overview & Monthly Detailed Sales) packaged into executable files using PyInstaller so everyone in the team can use it, regardless their technical skills. **Executable file is named WMG-SuperApp**
